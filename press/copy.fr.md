## Présentation développée

Phémios est une application de bureau pour explorer et écouter une CDthèque numérique. Elle réunit dossiers locaux et serveur Aède dans une interface configurable, avec pochettes conservées en cache, filtres visuels, collections et lecture native. Dossiers locaux et serveur dans un catalogue commun ; navigation par artistes, albums, pistes, genres, pays et labels ; Cover Flow ; filtres et recherche avancée ; annotations privées ; collections dynamiques ; analyses et spectres FlacCompagnon ; radio, podcasts RSS ; lecture native, file réorganisable et fondu DSP ; interface français/anglais.

Aède porte le catalogue et les règles métier ; Phémios propose une interface de bureau ; FlacCompagnon apporte les outils d’analyse audio. Leurs rôles sont complémentaires. Le projet privilégie une bibliothèque personnelle maîtrisée, des résultats explicables et des sources identifiées.
