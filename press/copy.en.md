## Extended description

Phémios is a desktop application for exploring and listening to a digital music collection. It brings local folders and an Aède server together in a configurable interface with cached artwork, visual filters, collections and native playback. Local folders and server in a shared catalogue; artists, albums, tracks, genres, countries and labels; Cover Flow; filters and advanced search; private annotations; dynamic collections; FlacCompagnon analyses and spectra; radio and RSS podcasts; native playback, reorderable queue and DSP crossfade; French/English interface.

Aède owns the catalogue and domain rules; Phémios provides a desktop interface; FlacCompagnon supplies audio analysis tools. Their roles are complementary. The project favours a user-controlled library, explainable results and identified sources.
