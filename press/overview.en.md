# Phémios — Editorial background

Phémios is a desktop application for exploring and listening to a digital music collection. It brings local folders and an Aède server together in a configurable interface with cached artwork, visual filters, collections and native playback.

## Features

Local folders and server in a shared catalogue; artists, albums, tracks, genres, countries and labels; Cover Flow; filters and advanced search; private annotations; dynamic collections; FlacCompagnon analyses and spectra; radio and RSS podcasts; native playback, reorderable queue and DSP crossfade; French/English interface.

## Approach

Source audio files and tags are unchanged. Personal data is separate from the catalogue and account-bound. External enrichment is explicit; missing information is not presented as a negative result.

## Availability

Development version. This kit announces no public Phémios download, price or release date.
