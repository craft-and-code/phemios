# Phémios — Dossier de présentation

Phémios est une application de bureau pour explorer et écouter une CDthèque numérique. Elle réunit dossiers locaux et serveur Aède dans une interface configurable, avec pochettes conservées en cache, filtres visuels, collections et lecture native.

## Fonctions

Dossiers locaux et serveur dans un catalogue commun ; navigation par artistes, albums, pistes, genres, pays et labels ; Cover Flow ; filtres et recherche avancée ; annotations privées ; collections dynamiques ; analyses et spectres FlacCompagnon ; radio, podcasts RSS ; lecture native, file réorganisable et fondu DSP ; interface français/anglais.

## Approche

Les fichiers audio et leurs tags ne sont pas modifiés. Les données personnelles sont séparées du catalogue et liées à un compte. L’enrichissement externe est une action explicite ; une information manquante n’est pas présentée comme un résultat négatif.
