# Phémios — Current state

Phémios uses SolidJS, TypeScript, Vite and Tauri 2 in its dedicated repository. Rust HTTP/cache policies remain independent of Tauri; IPC is centralized, versioned and narrowly allowed. The native app now connects to Aède's real authenticated library. Browser preview remains fictional and offline; native startup uses only a public local cache or an empty connection prompt.

Implemented interface corrections: histogram rails count distinct concerned artists, inclusive year/alphabet intervals support bound resizing and width-preserving movement, independent icons show either/both rails, whole-search focus border and selected-genre hover contrast are fixed. Redundant menu headings and the demonstration badge are removed. Compact mode has real cover rows; artist portraits/album covers retain stable squares. The footer has round play and transport controls, still disabled pending playback.

Countries use locally bundled Natural Earth boundaries on a rotatable/zoomable futuristic canvas globe, with pointer, keyboard and country-button alternatives. The new relationship graph shows at most 16 sourced local collaboration neighbours with shared-track weights; it does not invent dated band membership.

Native integration includes paged artist/album projections, raw-tag/current-owner search, artist discography and credited participations, attributed biography, already-fetched banners/backgrounds/portraits and native binary artwork cache. Public catalog and images are atomically cached under application data. Sessions stay native and process-only; private annotations are owner-scoped memory and server data. Resynchronization of the same catalog version reuses artwork. One worker warms shared image URLs; scrolling does not fetch covers.

Connected personal actions: immediate artist/album rating/favourite save and explicit tags/visual notes save, favourites, smart collection rule create/edit, confirmed history, server M3U save/list/download. Local administrator actions launch/cancel/poll FlacCompagnon and spectrum jobs on catalog-scoped albums; album pages read existing analyses and directly show available spectrum images. See `docs/design/native-integration.md` for contracts, storage and coherent module-size exceptions.

Verification on 2026-10-08: the authoritative gate passes on Node 26.10 / Rust 1.99 / macOS with 11 Node tooling tests, 48 TypeScript behavioral tests and 15 independent core Rust tests. Read-only native HTTP/cache testing against an isolated copy of the real catalog verified all pages and a served/cached cover (453 artists, 112 albums before adding the isolated audio sample). A stale cover-file regression was first reproduced and corrected in Aède; repeated-sync cache reuse has a failing-then-passing Rust regression. A 10,000-artist fictional test verifies association filtering, not UI frame rate.

The isolated Aède server and test account use separate temporary data, without copying personal accounts/annotations. One copied FLAC was indexed and used for successful analysis and spectrum jobs (both exit 0), an available analysis record, a valid served PNG, annotation/collection/M3U round trips and server-file verification. SHA-256 checks prove both original and copied audio unchanged. No credentials, personal titles or source paths are recorded in the repository.

Browser verification covers the histogram/contrast/globe correction milestones. The release macOS app builds. After the host was unlocked, native login/synchronization and binary-image IPC were visually verified against the isolated real library. Those checks exposed transient admission failures and an album-detail remount cycle during annotation updates; bounded GET-only retry, one-worker prefetch and stable reactive detail composition correct them. Final native acceptance verified offline public cache startup, persisted annotations after reopening, country zoom/filtering, compact mode, relation navigation, native M3U file publication, completed analysis/spectrum launches and direct spectrum rendering. The cache contains 148 of 152 advertised images; two covers and two backgrounds are rejected with HTTP 409 by the guarded server renderer. See `docs/coding/ui-acceptance.md`.

Remaining: real PCM playback/output/volume, synchronized lyrics/effects, mounted-player discovery/conversion/verification/copy, evaluated/manual collections, richer dated relationship sources, catalog events, cache pruning/quota, bounded decoded-memory/virtualization and cold/warm fast-scroll measurements. Minimum Rust 1.90 execution, Windows/Linux and physical outputs remain unverified. Missing services are visible; no silent demonstration fallback exists in native mode. `tools/check.sh` is authoritative before commits; `npm run build:native` bundles the host app.

Browsing refinements use canonical principal album artists for the main artist/country/genre navigation. Credited-only participants stay in the complete graph, search associations and credits. Rails start in years-only mode and can both be hidden; hidden bounds do not filter. Country selections are a union with Command-click on macOS or Control-click elsewhere, intersected with the other filters. Undated releases have an explicit explanatory option only while the year rail is visible and unknown dates exist. Rounded input focus borders, outside-click/Escape dismissal and connection-dialog focus containment are implemented.

The explicitly approved Milkdown kit provides visual CommonMark notes and undo/redo on artist/album pages. Formatting renders directly; Markdown remains the server storage format. Untouched note bytes are preserved, links/images do not trigger fetching/navigation, and initialization failure blocks save without discarding source. Compact, unframed star and heart glyphs share the same size. Native rapid-save acceptance exposed the stock listener debounce; save now reads the current editor document synchronously, independently of the presentation listener.

The Statistics sidebar page reads all existing Aède statistics and diagnosis contracts through a GET-only narrow allowlist. Whole-library measures include duration/storage, completeness, audio format/quality/sample rate, decades, origin, credit roles and paged artist/writer rankings. Page/schema validators reject inconsistent scan epochs, missing diagnostic counts, unsafe integers and malformed ratios. Navigating to another page returns the content area to the top, preserving current filters.

Desktop development now starts Vite before invoking Tauri and injects its actual bound URL. The default port is a single development preference, with automatic available-port selection. An explicitly supplied `PHEMIOS_DEV_PORT` is validated and strict; failure never reuses another application's server. Signal/exit cleanup closes the owned frontend. Collision tests prove that Vite and Tauri follow the same port and that runner/app arguments remain intact. Star spacing now uses a 14 px horizontal step for slightly overlapping glyph edges with separate hit areas; the existing selected-rating toggle continues to clear the note on a second activation.

Detail headers now have a compact translucent surface; return links sit at the far right of the shared artist/album toolbar, and artist biographies precede annotations. Stars/favourites send serialized single-field patches immediately; the explicit button saves only notes/tags. Server replies never replace the text draft, and failed icon writes restore the last confirmed value with a visible error. Stable entity/session keys prevent annotation updates from refetching in a loop.
