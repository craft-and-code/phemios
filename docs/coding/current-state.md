# Phémios — Current state

## Product and architecture

Phémios is a SolidJS/TypeScript/Tauri 2 desktop client with a framework-independent Rust core. Aède owns catalogue identities, query rules, accounts, analyses, copies and authenticated PCM. Local embedded and remote libraries can coexist in one source-qualified catalogue. Public catalogue/artwork caches are shared within an authority/catalogue; private data belongs to the exact source/account. Audio files and their tags are never modified.

The application includes artist presentations, Albums/Cover Flow, tracks, countries, genres, composers, labels, private favourites/ratings/tags/collections/history, a shared transient queue, radio, RSS podcasts, local audio CDs/CUE images, concerts, biographies/Encyclopedia, analyses, diagnostics, statistics and portable-device transfers. See the [user manual](../manual/en/getting-started.md) and [native integration](../design/native-integration.md) for capability and availability details.

It keeps 64 sanitized current-session failures, clears each source on logout/replacement and never retains request arguments or raw server responses. Unreadable personal data receives engine-compatibility guidance. This does not capture server stderr or make an older engine compatible with format-3 personal stores; stable collection IDs require published Aède 0.7.4 or later.

Small resident marks paint synchronously to avoid blank macOS WebView frames. General biography enrichment captures the submitting UI language for both sources; existing differently localized prose keeps its real language and attribution. Biography mentions also link known same-source artists, catalogue genres, available album years and already synchronized track placements, with an explicit choice between editions. Sidebar navigation also retains each view/collection shortcut’s main scroll offset (including the artist-card panel) for the session, with bounded restoration after delayed rendering and account/source retirement; explicit metadata filters start at the top. Attributed prose stays unchanged; see [biography navigation](../design/encyclopedia.md#artist-biography-reading) and [metadata presentation](../design/native-integration.md#label-logos).
- Administrative MusicBrainz review is available in External sources, with durable accept/reject/undo, optimistic revisions and explicit exact-artist biography jobs. Engines must advertise the new capabilities; native App rebuild/acceptance remains separate.
- Process-owned native sessions can be restored after a frontend reload; older hosts expose explicit disconnection recovery after an active-session conflict. Application exit still discards credentials.
- Every native dev/build automatically selects the latest published stable Aède source before fetching dependencies; the engine compilation itself remains locked/offline. Running processes still require restart after replacement. - CUE/BIN, CUE/FLAC and CUE/WAV use the local CD player without an Aède login; APE requires FFmpeg/FFprobe. A bounded 1,024-bucket progressive CD waveform uses already-read PCM and preserves pause/seek gaps. macOS discovers empty writers through DiscRecording. All three desktop platforms implement optional CRC-checked ASCII/Latin-1 CD-Text without online lookup: macOS TOC ioctl, Linux read-only SG_IO and Windows read-only READ_TOC_EX. Unsupported metadata never blocks playback. Platform query/response regressions run on the Mac host; Linux x86_64/Windows x64 library/test/example cross-compilation is checked separately from native hardware acceptance. Connected empty-drive recognition (ASUS SDRW-08U7M-U) and native CUE Play/Pause were observed on the development Mac. The maintainer confirms physical Mac ejection works (manual user evidence). Actual optical audio, real-disc CD-Text, native Linux/Windows acceptance and the cause of the reported intermittent optical dropouts remain unconfirmed.

Retained destination/root guards now protect configured local folders even for remote-only copies and revalidate after download and before publication; returning or changed roots retire the old preview. This remains metadata admission rather than race-proof confinement against concurrent filesystem replacement.
