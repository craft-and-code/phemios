## Phémios 0.3.1

Try Phémios in your browser with ten freely licensed recordings and the same published Rust audio foundation as the desktop application. This release also improves podcasts, globe navigation, refresh feedback and physical CD discovery. Original music files and tags remain unchanged.

## Added

- **Playable WebAssembly demo:** browse ten distinct covers in Albums/Cover Flow, explore artists and tracks, build a queue and use playback, seeking and volume without installing the App. The website’s **Try Phémios** button opens the public demo. Scott Buckley and Chris Zabriskie recordings retain their CC BY 4.0 attribution; demo audio is not added to desktop installers.
- A separate self-hosted Web profile connects to a same-origin Aède with memory-only named credentials and bounded original-file playback. Public GitHub Pages never asks for a private server login. This initial browser profile does not provide native devices, supervised playback, crossfade or complete desktop parity.
- Accept Apple Podcasts show and episode sharing links through a bounded public lookup, retaining account ownership and canonical RSS admission.
- Identify missing physical CD track names automatically through exact MusicBrainz TOC matches; conflicting editions retain generic titles. No Aède account is required.

## Fixed

- Restore browser demo globe geometry and appearance artwork under project/subdirectory deployments. Keep the final consumed position after natural playback completion and reload stale page state restored from the back/forward cache after its credentials were retired.
- Retire delayed media preparations, worklet gain changes and gateway responses when stopped or disconnected, preventing late starts, stale mute and unfinished proxy responses.
- Discover connected empty optical readers and retain their hardware names on macOS. Refresh can retry without inserted media; ejection uses a freshly verified unique system target. Keep circular Play glyphs centered.
- Hide the footer waveform and time placeholders when there is no playback.
- Keep Playback and Settings icon returns scoped to the active account, including delayed navigation. Give the country globe interruptible drag inertia and bounded rendering.
- Unify Refresh loader/Stop feedback, retire cancelled reads and account-replaced results, paginate podcast episodes and clarify remote catalogue-cache removal.

## Changed

- Native macOS menus retain the useful application, editing and window commands. Output and volume controls share the foreground color and displayed sections retain their active accent.
- Native and Web builds share UI and versioned audio source while keeping separate artifacts and capabilities. The Pages workflow builds and validates the WASM demo alongside the website and manual.

Each installer has its own SHA-256 sidecar. On macOS/Linux, compare `shasum -a 256 FILE` or `sha256sum FILE` with the sidecar; on Windows use `Get-FileHash FILE -Algorithm SHA256`.

- **macOS Apple Silicon:** M1 or later; open the DMG and drag Phémios to Applications. There is no Intel Mac build.
- **Windows x64:** Intel/AMD 64-bit Windows; use either MSI or NSIS EXE. Windows ARM64 and 32-bit packages are not included. The configured installer can download WebView2 when it is absent, so that installation step may need a network connection.
- **Linux x86_64:** Intel/AMD 64-bit desktop Linux; choose AppImage, DEB or RPM for your system. Builds use Ubuntu 22.04 and GTK3/WebKitGTK 4.1. AppImage/FUSE availability and distribution runtime libraries remain host prerequisites. No Linux ARM64 graphical App or 32-bit build is included; an Aède ARM64 CLI package is a different product.

### First launch and limits

macOS builds use complete ad-hoc integrity signatures for the App and its embedded engine, with App/DMG verification before upload. They are not Developer ID signed or Apple-notarized; Gatekeeper approval may still be required. Windows installers remain unsigned and SmartScreen may request review. Check the downloaded SHA-256 and follow the [first-run guide](https://craft-and-code.github.io/phemios/docs/en/getting-started.html). FFmpeg/FFprobe and optional device tools are not bundled.

The release workflow selects the latest published stable Aède once for all platforms and records its version/SHA in the build logs. Local preparation used published Aède 0.7.5; CI records its own actual selection. Stable collection identities require Aède 0.7.4 or later; a separately configured remote server may need updating/restarting. Language-aware biography refreshes and label-logo presentation require a compatible engine and explicitly selected enrichment services. Existing audio and retained biographies are preserved on failed enrichment.

Native build/test success does not establish installed runtime, physical audio/CD/device or live-provider acceptance. Real-disc CD-Text acceptance, native Linux/Windows optical behavior and the cause of reported intermittent optical dropouts remain unconfirmed. CD-Text is optional ASCII/Latin-1 disc metadata, not an online lookup. Concerts live-provider acceptance remains pending. Bit-perfect playback is unavailable on the remote f32/CPAL route. The stabilization campaign and PH-C09 retain their own acceptance requirements; this release does not close them or reattribute historical manual acceptance to a new installer.
