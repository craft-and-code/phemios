## Phémios 0.2.0

Phémios is a local-first desktop music player and library explorer. Its bundled Aède engine manages the catalogue; a separate Aède server is optional. You can use local and remote libraries together without changing original audio files or their tags.

### Included experience

- Browse albums, artists and Cover Flow, with filters and collaboration credits.
- Listen with a shared queue, available synchronized lyrics, visualizations and DSP controls.
- Keep personal favourites, ratings, tags, notes and dynamic collections.
- Explore radio, RSS podcasts, audio CDs/CUE images and saved articles.
- Read retained FlacCompagnon analysis results and explicitly request supported media jobs.
- Use the French/English interface, preferences and the [online manual](https://craft-and-code.github.io/phemios/docs/en/).

This release consolidates the existing application and stabilization corrections. The README now exposes the real native-build and website status badges, and download names distinguish both operating system and architecture. Application manifests, browser preview identity and HTTP client version identification follow 0.2.0.

Each installer has its own SHA-256 sidecar. On macOS/Linux, compare `shasum -a 256 FILE` or `sha256sum FILE` with the sidecar; on Windows use `Get-FileHash FILE -Algorithm SHA256`.

- **macOS Apple Silicon:** M1 or later; open the DMG and drag Phémios to Applications. There is no Intel Mac build.
- **Windows x64:** Intel/AMD 64-bit Windows; use either MSI or NSIS EXE. Windows ARM64 and 32-bit packages are not included. The configured installer can download WebView2 when it is absent, so that installation step may need a network connection.
- **Linux x86_64:** Intel/AMD 64-bit desktop Linux; choose AppImage, DEB or RPM for your system. Builds use Ubuntu 22.04 and GTK3/WebKitGTK 4.1. AppImage/FUSE availability and distribution runtime libraries remain host prerequisites. No Linux ARM64 graphical App or 32-bit build is included; an Aède ARM64 CLI package is a different product.

### First launch and limits

These builds are unsigned and not Apple-notarized. Gatekeeper/SmartScreen may require manual review; check the downloaded checksum and source before authorizing the App. See the [first-run guide](https://craft-and-code.github.io/phemios/docs/en/getting-started.html). FFmpeg/FFprobe and optional device tools are not bundled.

Native build/test success is separate from installed runtime, physical audio/CD/device, signing and provider acceptance. Earlier manual Mac acceptance covered its identified 0.1.0 DMG; it is not relabeled as a fresh 0.2.0 installation test. Concerts is implemented but live-provider acceptance remains pending. The stabilization campaign retains its documented limits; this release does not close PH-C09 or the campaign. Bit-perfect playback is unavailable on the remote f32/CPAL route.

The release workflow resolves the latest published stable Aède source once for all platforms and records its version/SHA in the build logs. Installer publication follows successful native jobs and the maintainer's explicit release authorization; tags and older release assets are not replaced.
