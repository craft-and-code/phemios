# Recent album additions

Nouveautés is an album-only toggle immediately before CoverSize in the fixed catalog toolbar, using the former menu's sparkles glyph. It intersects the existing search, year, alphabet and facet criteria and preserves the selected grid/list/Cover Flow presentation. It uses actual Aède catalog entry timestamps within the inclusive last thirty days; unknown/future dates are excluded. Result counts and histogram bins share one clock, refreshed each minute only while the flag is observed. Tout afficher clears it, and leaving Albums does not apply it to another view.

The retired navigation id is removed from default and customized Settings navigation, including hidden entries and renamed labels, without resetting unrelated order, names or separators. Legacy #/recent links resolve to Albums. The old standalone view is removed.

Aède's current browse-v1 contract cannot express catalog-entry windows. Collection creation is therefore explicitly disabled with an explanatory tooltip while this client-side filter is active; no collection silently drops the criterion or stores a fixed snapshot as a dynamic rule. Ordinary collections remain available with the toggle off.
