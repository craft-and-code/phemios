# Explicit browsing state, missing albums and labels

## Filters and navigation

Each section owns its own in-memory search and browse criteria. Selecting countries or genres never silently narrows the Albums section. Returning to the original view retains its selection; detail return still restores its origin and scroll. Dedicated artist/album/track/label pages have no histogram rails. Explicit artist genre/country and album-year links initialize the destination view rather than copying unrelated selections. Countries starts with both rails hidden; other catalog lists retain years by default.

The separate active-filter summary row is omitted at the user’s request, so changing rail bounds never inserts content above the catalogue. The existing rail-toolbar Reset remains the single action for clearing criteria. Hidden rails do not filter. The global year domain follows owned editions only; missing studio suggestions belong exclusively to artist discographies. Search and source criteria remain scoped to their sections. Density/sort remain visible presentation choices and do not remove results.

## Missing albums

Authenticated sources read the additive owner-private Aède missing-studio-album contract after login/snapshot changes. Complete bounded pages retain their epoch, source and session; private decisions stay in memory and never enter the public artwork/catalog cache. Unsupported servers show an update/restart explanation, partial source failures remain explicit, and account replacement hides the earlier owner's answer immediately.

Settings → Libraries includes an immediately saved, account-synchronized Show missing albums choice, enabled by default when migrating existing tool preferences. Disabling it omits missing tiles and their status/retry/restore section from artist discographies; unmounted tiles do not request artwork. It preserves all owned editions and the separate reversible owner-private set-aside decisions.

Only principal artist discographies interleave owned editions with attributed MusicBrainz missing studio albums. Discography and participation grids sort from oldest known year to newest, with undated entries last and stable title/reference ties, independently from the catalog title-sort control. Missing entries have their own type and cannot be passed to playback/album-detail APIs. At the user’s request, visible missing tiles automatically request Cover Art Archive artwork through an explicit authenticated Aède POST. An intersection observer limits acquisition to nearby cards; one queue per source deduplicates appearances and discography tiles. Validated images remain in Aède’s separate data cache and Phémios’s authority/account/catalog-epoch artwork cache. Account replacement hides/revokes old object URLs and drops queued work. Auditors use cache-only GET, old servers without the capability stay on the fallback, and an archive-negative answer is not an error. Without known artwork, an opaque centred disc glyph and Missing marker preserve square geometry. A small top-right cross hides the suggestion; the extra link/action row has been removed. Their title still opens the relevant artist. Hide explicitly saves a reversible set-aside decision to that source/account; Hidden suggestions exposes Restore. Auditors cannot mutate. No audio file, catalog album or source fact is deleted. These are gaps in already-fetched discographies, not a promise of exhaustive worldwide release coverage.

## Rated albums and labels

Rated albums parallels Favourites: direct album ratings or principal-discography albums of rated artists qualify, never incidental personnel credits. Inclusive minimum and maximum star choices use the same compact controls as annotations. Defaults cover one through five stars; moving a bound past the other moves the opposite bound to preserve a valid interval. Repeating its selected threshold returns to one star, while repeating an annotation’s selected rating still clears that personal rating. A stronger inherited artist rating is labelled Artist on its tile rather than being presented as the album's own rating. The existing selected owner/source boundary applies.

Labels presents bounded 50-row source windows in a common card grid, retaining source badges only with both catalogs. Search and page changes are explicit; no complete track download or external metadata fetch is introduced. Label detail reuses Aède's existing release references and its additive cached biography with source, language and licence, rendered as plain paragraphs. Expired Discogs profiles remain excluded by Aède’s existing freshness policy. Unknown biography/cache gaps and disconnected sources stay explicit. This first label profile requires the current source session; offline label caching is not claimed.

## Trial playback layout and identity proposals

The library and radio footers keep Play/Pause on the central axis and place an independent small Stop at the bottom-right edge of the centred Play button. Previous/Next, progress and volume retain their actions; this is a reversible layout trial with no playback-protocol change. Keyboard labels/focus remain present.

`assets/brand/proposals/` contains standalone SVG application icons and editable transparent wordmarks for Phémios/Aède, plus a self-contained comparison board. They retain the shared dark/off-white/accent-dot identity. The accepted p silhouette remains the basis for Phémios. These review proposals do not replace either active product's resources automatically.

## Shared empty result states

Rated albums, artist/album grids, favourites and personal collections/history, Tags, Tracks, Labels, Relations, Doctor and Radio use a common centred icon/message result state. On standalone result pages it fills the space remaining after criteria and source controls; nested album sections retain a bounded empty state. Notices for authentication, partial reads and errors remain distinct, with retry actions spaced from their messages.

Missing-cover loading exposes loaded, absent and failed counts, with an explicit retry for failed cards. Curated CAA front thumbnails avoid the JSON index when possible; all publication remains source-scoped and validated.

Source-scoped cover acquisition can briefly contend with personal-store reads. The native client applies its bounded backoff to idempotent GET 409/429/503 replies; mutation requests are still never replayed automatically. This avoids a transient read lock becoming a persistent page warning while preserving final failures and authentication boundaries.

## Personal controls and destination discovery

Command-click (Mac) or Control-click (Windows/Linux) toggles tag choices in a union across directly tagged artists, albums and tracks; a normal click replaces the selection. Empty messages keep one sentence and share their section’s navigation glyph. History reset appears only when retained history exists. Collection deletion has an explicit confirmation, targets the captured owner/source and removes only the saved rule. M3U browsing explains its download purpose and groups exact legacy repeated saves through the advertised server summary contract without deleting data.

Settings → Tags lists the current owner’s active vocabulary in the shared Settings card. Deletion removes an entry from this list and autocomplete without exposing a restore list or mutating existing music annotations. Explicitly entering and successfully saving that tag again restores its vocabulary entry. Editing a note or saving unchanged tokens does not restore deleted words. Suppression is partitioned by authority/account (the owned local engine uses a stable app authority rather than its ephemeral listening port), saved before UI confirmation and never removes music annotations. Unreadable settings are preserved. Radio initializes one bounded station search from a saved country choice or an explicit OS locale region, never language-only geographic inference or geolocation. Manual changes persist; no stream starts automatically.

Analyses uses bounded retained-coverage pages with whole-catalog file totals and per-album present/missing/stale/failed results and available spectra. Search covers album title and principal artist, pagination preserves scan epochs and unsupported servers explain the required update. Result inspection/download and explicit admin jobs remain separate; complete analysis/spectrum actions are unavailable unless recomputation is explicitly chosen. Aède reuses valid saved measurements during an ordinary analysis job.

External players now uses native read-only discovery of mounted destinations, independently of Aède’s library source. Fixed OS commands and bounded output provide mount evidence rather than a codec profile or write guarantee. Refresh exposes external volumes and mounted network shares; unavailable candidates disappear. macOS uses diskutil’s internal/bus metadata to exclude internal Recovery volumes and disk images, within one bounded discovery deadline. macOS host execution and parser fixtures are distinct from unverified Windows/Linux native execution. Copy, conversion and destination verification remain separate work; no mock transfer action claims to run.

Editing annotations focuses the tag field; saved/editable pills share one height and the removal hit target fits inside that geometry. Missing tags and notes each have a plain empty indication. Label paging uses centred arrow buttons and an explicit page label. Collection creation opens a focused inline panel only on demand; deletion uses a compact per-row confirmation that preserves source/owner checks. Radio hearts are enclosed by the station card border.

Catalogue cover cards expose a small sibling playback button on pointer hover or keyboard focus, using the existing source-scoped playback selection. Album, tagged target and artist cover navigation remains a separate link; absent/missing studio claims have no playback action. Compact album rows move playback after the right-aligned year, with the same outer inset as the cover. Touch layouts keep the control visible. No playback occurs on navigation or passive cover loading.

Coverage actions expand immediately beneath the selected album row. Starting, queued and running tasks display a visible activity indicator; confirmed job state disables duplicate launches, and completed coverage refresh remains server-owned. Analysis export notices render outside the table with bounded wrapping, while standalone download notices also wrap. Late download completion is ignored after source/account/reference replacement.

Artist-card Play always selects the artist identity, independently from the associated album used as illustration. Aède's existing principal-discography projection supplies the oldest-to-newest owned album queue, excluding guest appearances. Compact-row Play uses the shared rounded-square control shape; cover overlays remain round with a centred triangle. Audio-output discovery admits one request at a time, exposes visible activity for at least one second and retains genuine failures. Reset/disposal cancels its display timer and rejects late results from a previous session without blocking transport actions.

Personal collection creation is available from rated albums and favourites as well as the existing artist/album/country/genre catalog selection. Rated rules retain both inclusive bounds and the search; favourites retain owner-private direct-album or principal-artist semantics. Both are evaluated again on Aède, so later ratings/favourites affect the result. Their additive capability is checked before saving to legacy servers. Collection cards show their name and actions without redundant dynamic/catalog descriptors. The adjacent pencil opens a focused name editor; one authenticated atomic PATCH preserves the original expression/creation date, refuses normalized-name collisions and reports failures without deleting or copying the rule. Audio output summary and mute controls share a vertically centred box; summary hover explicitly uses the accent.

## Cover, row and footer actions

Artist grid Play is positioned inside its own cover container, independent of card text height or the last grid row. Compact artists retain a separate rounded-square Play at the right. Track primary rows use a full-height detail link hit area; album-context links and playback/analysis/spectrum actions remain independent, with expanded analysis outside that hit area. Thin themed scrollbars preserve native OS scrolling and visibility preferences.

Rated and Favourite collection actions share the right inset, refuse an empty visible selection, and retain their frozen criteria when opened. Collections uses the same icon/inset for its existing collapsed creation form. Podcast loading activity occupies the next full line below its subscription controls.

The library footer exposes the current track's personal heart next to the title. Writes explicitly capture that track, its source and account, send only the loved field, and cannot publish a late answer into the next track/account. Read-only/offline/duplicate requests are refused. Detail annotations react to a successful footer heart change without overwriting notes or tags. Audio settings has a top-right close action and a small refresh beside the output menu.

Analysis headers retain their table design and expose one active up/down chevron plus accessible sort direction. Missing counts descend by default; numeric columns start descending and Album starts ascending. Aède orders the complete matching catalog before paging, with stable ties; changing a column returns to the first page. Older servers expose an explicit update/restart error instead of sorting only the visible window.

## Artwork and measurement refinement

Missing-album dismissal uses the same 30 px top-right overlay geometry and 8 px inset as cover Play. Coverage artwork remains 48 px square in both density modes, including unavailable-image fallbacks.

Committed pills still require their cross for removal. ### Labels

Labels use full-height name/count rows with an independent final Play square. Aède owns the chronological label queue; the shell's target also follows a label detail. Detail lists expose scoped year and title-alphabet histogram rails (years initially visible), inverse order, compact density and a final collection action. Collections freeze the original stable label key and originating library/account at opening; source changes cannot redirect the write. Future albums matching the retained label and criteria join on evaluation. Discogs prose retains a linked provider notice; opening the detail performs no external enrichment.

## Retained Cover Flow and live history

Cover Flow position is session-owned by the shell rather than its temporary renderer. A stable visible reference survives leaving and returning to Albums, including appended catalog entries. A reference outside the current filtered result falls back to its first row; explicit reversing starts at its new first row. Alphabet landmarks reflect the displayed titles and order. The artwork accent border supplies the card focus indication without an additional link outline.

Elastic scroll chaining is disabled at the document and panel boundaries. Actual overflow panels and Cover Flow wheel navigation remain scrollable. History polls the authenticated personal endpoint at a two-second interval only in its active view, never overlaps pending reads and retains unchanged track resolutions. No client-declared playback event is added.

## Track metadata navigation

Track raw file tags retain each supplied value separately. Performer/artist/album-artist, composer, lyricist, conductor, arranger, producer, remix and engineering names resolve only unique exact catalogue/credit identities on the same source. Album values prefer the current edition before a unique matching title. Without an unambiguous identity, the action opens the appropriate catalogue search instead of inventing a reference. Genre actions select that genre; label/publisher/organization values explicitly read the same source’s `/api/v1/label?name=…` and open its validated exact label detail; known four-digit date/year prefixes open the corresponding album-year interval. Unrelated raw text stays read-only. Source qualification prevents equal names in the other connected library from becoming accidental destinations.

History title navigation and replay share the visited track identity, including albumless tracks. The independent final Play square uses existing native queue admission; an unresolved/deleted visit retains its diagnostic and disables replay. Dates/listening durations remain beside the action, with a two-row narrow-screen layout. The current-output row also exposes replay without creating a synthetic history event.

Navigation name editing occupies the existing name column. Visibility/icon/drag and ordering controls retain fixed columns; its single-line input, Save and Cancel align on the same row without sharing a flexible half-width checkbox label. Long unedited names ellipsize with their full tooltip.
