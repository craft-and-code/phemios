# RSS podcast subscriptions

Podcasts sits beside Radio under Music sources. A user explicitly adds a public RSS/Atom URL or refreshes an existing subscription. Opening/navigating the page reads retained local metadata only and never starts audio or fetches a feed automatically. The first version has no directory, account requirement, OPML import or automatic episode download.

The native ureq client is separate from Aède authentication. URLs exclude credentials, local files, fragments and non-HTTP(S) schemes; only ordinary HTTP(S) ports are allowed. Its resolver checks the actual socket addresses used by every initial/redirected connection, refusing private/link-local/loopback/non-public addresses. DNS and the entire request are bounded; redirects stop after three and XML bodies after eight MiB. No Aède bearer, service key or cookie is sent. Only UTF-8 XML is accepted in this version. One serialized native reader bounds concurrent feed work.

The system WebView parses XML, refusing DTD/entity declarations and parser errors. RSS audio enclosures and Atom enclosure links become finite episodes; HTML summaries are shown only as bounded plain text, never inserted markup. Missing durations/dates remain unknown. Stable episode IDs remove repeats; the newest 200 available entries are retained. Relative enclosure addresses use the supplied feed address. Media URLs exclude embedded credentials and obvious local/private literal hosts. Finite audio uses the WebView’s supported codecs and system output, like Radio; it does not claim CPAL output selection, DSP or bit-perfect playback.

Subscriptions and retained episode metadata live in the application’s local preference storage independently of Aède accounts (versioned document, at most 100 subscriptions/four MiB). Writes succeed before UI confirmation. Malformed/unreadable documents are preserved and shown as errors; there is no silent reset. Refresh replaces only that feed’s metadata; unsubscribe removes only its retained subscription and can be reversed by subscribing again. No source audio file or Aède music annotation/history is touched.

Podcast, radio and library playback are mutually exclusive. The footer exposes finite duration/position, pause/resume without rejoining or resetting, seek, mute/volume and attached Stop. Late starts cannot revive stopped media; stalled/unsupported streams fail visibly. Feed refresh and navigation never imply playback. Offline subscriptions remain browsable; episode audio requires its publisher’s availability. Physical sound, cross-platform codecs and other providers remain separate acceptance work.

Subscription acquisition exposes activity beneath the input row. Refresh instead replaces its own glyph with an accessible spinner for the real request lifetime, restoring the glyph on success or failure; both actions prevent concurrent feed requests.
