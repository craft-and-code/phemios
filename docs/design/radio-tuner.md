# Radio tuning interactions

The dial indexes the current Radio Browser result page; its marks do not represent FM frequencies. Directory browsing and stream playback use the existing account-independent radio services. Only saved favourites require an authenticated Aède account.

## Preview and commit

A pointer gesture or held range key previews the selected station immediately and commits exactly the final station on release, including when no radio was playing. Clicking a station row starts it immediately; selecting an already playing station does not restart it. Search completion, page mounting and retained favourites never initiate playback.

A primary horizontal drag pauses an engaged stream once after four pixels so only the tuning feedback remains. The final release starts the selected stream; no intermediate station is resolved. Cancellation, focus loss, hidden documents, replaced results and disposal leave the interrupted radio paused without an unsolicited restart. Later explicit Stop, Pause or Play actions replace the pending gesture through a transport revision. Continued input/change events from a canceled gesture cannot revive it. A new pointer/key gesture or row selection is required; a standalone accessibility input/change pair still commits its final choice.

One public result page, its selected dial index, country, search fields and submitted criteria are retained in process memory across route remounts. This stores at most fifty validated station rows, never favourites, account identity or resolved media URLs. Returning to Radio performs no replacement directory read and highlights the active station when present in that retained page. Draft search edits remain distinct from the submitted criteria used for pagination. Exiting the app clears this browse session.

## Local tuning feedback

A primary pointer drag plays the wandering-whistle texture explicitly chosen by the user. The feedback controller also supports three original synthesized textures (radio static, wandering whistle and fluttering interference) and optional once-per-gesture random choice for callers without a fixed preset. Phémios fixes `whistle`, so no runtime random draw occurs and only one 64 KB buffer is cached. Feedback begins after more than four horizontal pixels of movement; clicks, keyboard selection and stationary gestures produce no feedback. Pointerdown prepares Web Audio silently to preserve WebKit user activation. The texture remains unchanged throughout that gesture. The feedback generator owns no stream command; the tuner pauses the previous station and commits playback separately. A failed or late context resume cannot start an abandoned gesture or turn a radio stream failure into a tuning action.

Release, cancellation, focus loss, hidden documents, directory replacement and page disposal stop the feedback with a 40 ms release envelope. A page owns one lazy AudioContext, at most one active and one retiring voice, and at most three cached mono buffers of 16,000 float samples each (192,000 sample bytes in total). Bursts of gestures retire the oldest release voice before admitting another. Sources disconnect on completion or bounded wall-clock cleanup. After a stationary click or the last release voice, the unused context is suspended; another gesture resumes the same context, waiting for any preceding suspension. A canceled late resume returns to idle. Disposal releases buffers and closes the context after the short fade. No recording, decoder dependency, provider request or network asset is involved.

The feedback follows the volume of the currently displayed footer transport, including preemptive mute with no playback. A master gain makes mute immediate for both the current and retiring feedback voice. Optional feedback errors are displayed separately from the radio transport; they do not alter playback state. The synthesis uses silent seams and short onset/release ramps. Isolated muted macOS acceptance verifies native WebKit pointer admission and active/idle station switching without feedback errors; physical listening remains unverified.

## Favourite owner identity

The presentation identity combines source, server authority and stable account ID. A username rename retains the same loaded favourites; a recreated same-name account clears the preceding projection before reading its own preferences. The stored `phemios.radio-favourites` key, version-one station schema and server GET/PATCH requests remain unchanged. Source and server identity are never inferred from a station's country or name.

## Verification boundary

Controller tests reproduce the former selection-only dial, idle commitment and remount losses, exercise coalesced pointer/key gestures, stream interruption, cancellation, transport/page replacement and disposal, and hand only the final choice to the actual radio playback controller with injected fictional media. Account tests verify stable-ID naming and replacement behavior. Feedback regressions verify once-per-drag selection, stationary clicks, pointer identity, delayed resume rejection, gain/mute, bounded voice overlap, buffer reuse and context retirement; the synthesized PCM is finite, distinct and silent at its loop seam. Isolated macOS host acceptance additionally verifies a live directory, idle selection and switching between muted live streams. These checks do not establish physical audio or keyboard/assistive range-event ordering on each platform.

## Audition exports

The three textures are original synthesized PCM rather than songs or third-party recordings: `static` is modulated radio noise, `whistle` adds a wandering tuning whistle, and `flutter` combines intermittent interference with a lower tone. Eight-second audition WAV files in ignored `dist-native/radio-tuning/` repeat the exact one-second 16 kHz generator output, apply the app's 0.13 feedback envelope gain at full master volume, and use its 15 ms attack/40 ms release. Float32 WAV retains the generated samples without a decoder dependency; Core Audio file inspection verifies their format/duration. The user selected the whistle preset; the two other exports/generators remain available as comparison material, while app gestures use only whistle.

## Measured dial wave

The real SVG wave consumes only the current radio voice or the current local whistle loop, never library playback, podcasts, microphone or system audio. The gesture signal takes precedence while tuning. One 2048-float sample buffer (8 KiB) and at most 129 SVG points are reused; drawing is limited to approximately 30 Hz and stops while hidden, outside the viewport or disposed. Silence and unreadable samples retain the travelling idle wave; finite PCM is clamped to the dial bounds. Sampling is before footer gain/mute, as for library indicators.

The explicit start gesture prepares a silent context before asynchronous library admission or URL resolution, retaining WebKit user activation without playing an abandoned stream. HLS closes that unused context. A CORS-enabled progressive radio stream is routed through one disposable MediaElementAudioSource, analyser and output gain. Failure to open it with CORS retries ordinary playback once without an analyser, preserving listening; retired elements, nodes and contexts are released. HLS URLs retain the system media path without optional routing. WebKit's HLS MediaElementAudioSource currently yields zero samples despite audible playback, and cross-origin resources without CORS must yield silence under the Web Audio specification. Those streams therefore keep the idle wave rather than invented sound levels. See [WebKit HLS limitation](https://bugs.webkit.org/show_bug.cgi?id=306493) and [Web Audio security rules](https://www.w3.org/TR/webaudio-1.1/#security-and-privacy-considerations). A native radio decoder would be a separate future change.

Behavioral ports verify pre-mute sampling, CORS refusal/retry, untouched HLS, radio-only admission, tuning lifecycle and complete sample invalidation on pause/Stop/disposal. The component explorer uses synthetic PCM to exercise the actual renderer without sound or service access. These checks do not imply acoustic output or universal station analyser support.
