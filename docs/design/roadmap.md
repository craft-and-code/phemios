# Incremental roadmap

1. **Foundation** — SolidJS/TypeScript/Vite, Tauri shell, independent core, typed bridge, minimal capabilities and lockfiles.
2. **Engineering configuration** — EditorConfig/Prettier, lint, behavioral tests, authoritative checks, project instructions and documentation.
3. **Offline library shell** — Aède identity, hideable navigation, artist/album browsing, year/alphabet/both rails, drag movement, inclusive filtering and explicit demonstration data.
4. **Read integration and artwork** — authenticate to Aède, pagination/events, native artwork/prose contract, persistent artwork cache, virtualized working set and cold/warm scroll benchmarks.
5. **Personal/library pages** — full artist/album pages, provenance, annotations, collections, ordered server playlists and M3U downloads, broad owner-scoped search, visual Markdown notes and whole-library statistics.
6. **Discovery** — rotating/zooming country globe with bundled geographical data; bounded, attributed relationship graph; keyboard alternatives.
7. **Playback and analysis** — output capabilities, volume, consumption-clock PCM, synchronized lyrics, signal visualization, explicit FlacCompagnon/spectrum tasks and direct results display.
8. **External player export** — mounted-device discovery, existing destination selection, dry-run, conversion/verification options, cancellation/resume and real transfer acceptance through Aède's rules.
9. **Release acceptance** — platform builds, revocation/account isolation, cache lifecycle, measured large-library behavior, native/physical output and external-drive checks.

Each coherent part gets its own verified commit. These phases are implementation boundaries, not claims that server or physical acceptance already passed.

Phases 1–3 are complete. Phase 4 has authenticated paging, native projections and persistent artwork; events, cache quotas, virtualization and scrolling benchmarks remain pending. Phase 5 has connected visual artist/album annotations, detailed statistics and diagnosis reads, favourites, collection rules, history and album M3U save/download; evaluated/manual collections and richer credit pages remain pending. Phase 6 has the geographic globe and bounded local collaboration graph; dated membership provenance remains pending. Phase 7 has explicit analysis/spectrum jobs and direct results; playback/output/lyrics/effects are still unavailable. Phases 8–9 remain acceptance work. Read current-state and native-integration before inferring broader support.
