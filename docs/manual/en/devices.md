# Take your music with you

External players starts with music selection, then destination selection. Transfers reuse Aède’s rules without changing originals.

## Compose a transfer

Choose music to copy searches tracks, albums, artists, collections or M3U lists. Plus controls append to Music to transfer. Remove unwanted selections before preparation.

Choose a detected device or a folder through the native picker. A folder can be on a mounted external drive. Removing a manual destination forgets its permission in Phémios; it neither deletes files nor ejects a drive.

## Inspect the preview

Preview shows planned output names, including conversion extensions. Check format, collisions and choices before writing. Source size is not a final MP3 size estimate.

Conversion profiles apply to eligible sources; already lossy files are not necessarily re-encoded. Some formats need external tools. Detailed copying, conversion and verification rules belong to [Aède](https://craft-and-code.github.io/aede/docs/en/cli/copy.html).

## Device differences

Disks and conventional storage players use file copying. MTP needs a recognized device. Compatible Apple-firmware iPods can require podkit to update their music database; copying arbitrary files is insufficient. Rockbox uses ordinary file copying. Not every model is supported.

If a device is reported incompatible, check its model and the displayed guidance before continuing. Phémios does not format drives or replace firmware. Wait for copy/verification confirmation, then use Eject where available. Disconnecting during writing can leave incomplete files.
