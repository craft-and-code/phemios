# Votre musique, vos repères

Les annotations appartiennent au compte connecté. Le catalogue peut être commun ; vos favoris, notes, étoiles, collections et historique ne deviennent pas ceux des autres utilisateurs.

## Annoter sans modifier les fichiers

Le cœur et les étoiles enregistrent directement la modification. Recliquez sur une note identique pour l’enlever. Le crayon ouvre l’édition des tags et des notes personnelles ; validez ces modifications avec Enregistrer.

Entrée crée un tag. Vous pouvez saisir plusieurs tags séparés par des virgules, puis appuyer sur Entrée. La virgule seule ne valide rien. La croix d’une pastille la retire. Les tags existants servent à l’autocomplétion ; Paramètres → Tags permet de gérer ce vocabulaire. Les notes disposent d’une mise en forme visuelle et d’un téléchargement quand elles contiennent du texte.

## Créer une collection qui évolue

Dans les vues proposant cette action, affinez les critères puis cliquez sur l’icône de création de collection et donnez un nom. La collection conserve les critères : les futurs albums correspondants pourront la rejoindre.

Collections permet de consulter les albums, renommer, lancer la lecture ou supprimer la collection après confirmation. Supprimer une collection ne supprime pas la musique. La durée n’est affichée que lorsqu’elle est connue.

## Construire une liste de lecture

Listes de lecture affiche la même file que le volet de la vue Lecture. Elle démarre vide au lancement. Le plus cherche des pistes, albums, artistes, M3U ou collections. Un plus associé à un Play ajoute à la suite ; Play lance une sélection.

Glissez les poignées pour réorganiser les occurrences. Les tris numérique, alphabétique et inverse permettent d’essayer un autre ordre. La croix rouge retire une occurrence ; vider la liste arrête la lecture. Parcourir les fichiers M3U ouvre les listes présentes dans les dossiers et les exports accessibles à votre compte. Les chemins d’un M3U doivent pouvoir être résolus par sa source.
