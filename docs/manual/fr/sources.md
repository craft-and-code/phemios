# Radios, podcasts et CD

## Trouver une radio

Radio consulte Radio Browser indépendamment d’une connexion à Aède. Choisissez un pays avec le globe et explorez ses stations. La flèche circulaire du globe recentre votre pays proposé ; les résultats dépendent des informations publiées par les stations.

Cliquez sur une station pour écouter. Glisser le cadran coupe la station et fait entendre le son d’accordage ; relâcher lance la station choisie. Les favoris se trouvent sous le globe et appartiennent au compte. Sans compte, la recherche et l’écoute restent utilisables, sans vos favoris personnels. Un flux peut être indisponible ou incompatible même si sa fiche existe.

## S’abonner à un podcast

Ajoutez son adresse de flux RSS, puis S’abonner. Un lien de page web ou de partage n’est pas toujours un flux RSS. Choisissez un épisode pour écouter ; les épisodes écoutés sont distingués. Le téléchargement est disponible pour conserver un épisode sur la machine.

Les abonnements et l’état d’écoute sont privés par compte sur cet appareil et inclus dans la sauvegarde Phémios du compte sélectionné. Le désabonnement demande confirmation.

## Lire un CD ou une image

CD audio fonctionne sans serveur Aède et sans enregistrement d’utilisation par compte. Branchez un lecteur, insérez un CD audio, puis choisissez le disque. Sans matériel reconnu, les commandes correspondantes restent indisponibles. L’éjection est désactivée pendant sa lecture.

Ouvrir une image permet de choisir un CUE accompagné de BIN, WAV ou FLAC. APE nécessite FFmpeg/FFprobe installés. Ce n’est pas un outil d’extraction ni de modification du disque. Les comptes supervisés conservent leurs restrictions d’écoute.

## Préparer une sortie concert

Concerts recherche les dates disponibles pour les artistes via JamBase. Renseignez votre clé dans Paramètres → Sources externes. Le plafond local limite les appels gratuits ; l’absence de résultat n’établit pas qu’un artiste ne se produit jamais. Les conditions et limites du fournisseur s’appliquent.
