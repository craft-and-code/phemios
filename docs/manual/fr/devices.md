# Emporter sa musique

Lecteurs externes commence par la sélection de musique, puis le choix de la destination. La copie réutilise les règles du moteur Aède ; elle ne modifie pas les originaux.

## Composer le transfert

Choisir la musique à copier recherche des pistes, albums, artistes, collections ou listes M3U. Les plus ajoutent les éléments à Musique à transférer. Retirez les éléments inutiles avant de préparer l’opération.

Choisissez ensuite un périphérique détecté, ou un dossier avec le sélecteur natif. Cette dernière option peut désigner un disque externe monté. Retirer une destination manuelle oublie son autorisation dans Phémios ; ce n’est ni une suppression de fichiers ni une éjection.

## Lire l’aperçu avant de copier

L’aperçu montre les noms de sortie prévus, notamment après conversion. Il permet de vérifier le format, les collisions et les choix avant toute écriture. Une taille source n’est pas la taille finale estimée d’un MP3.

Les profils de conversion concernent les sources éligibles ; les fichiers déjà avec perte ne sont pas systématiquement réencodés. Certains formats requièrent des outils externes. Les règles détaillées de copie, conversion et vérification sont chez [Aède](https://craft-and-code.github.io/aede/docs/fr/cli/copy.html).

## Selon votre lecteur

Les disques et lecteurs à stockage classique utilisent la copie de fichiers. MTP nécessite un appareil reconnu par le backend. Les iPod avec firmware Apple compatibles peuvent nécessiter podkit pour leur base musicale ; un simple glisser de fichiers ne suffit pas. Rockbox utilise la copie classique. Tous les modèles ne sont pas pris en charge.

Si un appareil est signalé incompatible, vérifiez son modèle et les indications affichées avant de poursuivre. Phémios ne formate pas de lecteur et ne remplace pas son firmware. Attendez la confirmation de fin de copie/vérification, puis utilisez l’éjection quand elle est disponible. Un débranchement pendant l’écriture peut laisser des fichiers incomplets.

Changer de compte efface les détails de progression du transfert du compte précédent. Les actions sur le périphérique restent indisponibles tant que le suivi natif indique un transfert en cours.
