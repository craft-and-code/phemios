# Personnaliser et partager

## Un espace à votre façon

La roue crantée ouvre les paramètres. Langue sélectionne français ou anglais. Apparence ajuste les couleurs et la taille générale des pochettes ; un thème peut être exporté, importé ou réinitialisé. Navigation masque, renomme et réordonne les menus et leurs séparateurs. Les noms personnalisés ne sont pas traduits automatiquement.

Raccourcis permet de configurer les combinaisons. Les champs de saisie et dialogues gardent leur comportement d’édition. Les réglages sont conservés soit dès l’action, soit avec le bouton d’enregistrement proposé. Une erreur de sauvegarde reste visible : elle n’est pas une confirmation.

Dans Lecture, Garder l’écran actif pendant la lecture demande temporairement au système de maintenir l’écran. La pause et l’arrêt libèrent la demande. Les politiques et capacités du système peuvent limiter ce comportement ; aucun réglage permanent de verrouillage n’est modifié.

## Plusieurs comptes, un catalogue

Aède porte les comptes, permissions et règles de contrôle parental. Phémios les présente dans les réglages. Un administrateur peut limiter artistes, radios, podcasts et budgets d’écoute d’un compte supervisé ; les détails d’administration et de verrouillage sont dans le [manuel Aède](https://craft-and-code.github.io/aede/docs/fr/server/accounts.html).

Les dossiers et le catalogue peuvent être communs. Tags personnels, étoiles, favoris, historique et collections restent privés. Se déconnecter cache les données du compte précédent ; une lecture invitée n’adopte pas ses annotations.

## Sauvegarder ses choix

Sauvegarde exporte les préférences de présentation, organisation des menus, raccourcis et les podcasts/articles enregistrés du compte sélectionné sur cet appareil. L’import présente ce qui sera restauré.

Ce fichier n’est pas une sauvegarde de vos morceaux, ni un export intégral du compte Aède. Les mots de passe, clés API et règles parentales sont exclus. La sauvegarde du catalogue et des données serveur se fait avec [Aède](https://craft-and-code.github.io/aede/docs/fr/cli/backup.html). Conservez aussi une copie indépendante de votre musique.

## Où vont les fichiers téléchargés ?

Les téléchargements directs arrivent dans le dossier **Téléchargements** de votre système : textes complets des biographies et articles, épisodes de podcasts, notes personnelles, M3U, rapports JSON et images de spectres. Aucun sous-dossier Phémios, Local ou Serveur n’est ajouté. Un nom déjà présent reçoit un suffixe ; le fichier existant est conservé. Les fichiers téléchargés auparavant restent à leur emplacement initial.

Les exports **CSV**, **thèmes** et **sauvegardes de préférences** ouvrent toujours une fenêtre d’enregistrement : vous choisissez leur destination. La copie vers un lecteur externe conserve la destination explicitement sélectionnée. Les paroles récupérées par Aède et les données privées/cache de l’App gardent leur stockage propre.
