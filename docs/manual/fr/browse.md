# Explorer la CDthèque

Albums place les pochettes au premier plan. Artistes rassemble les artistes principaux des albums ; les musiciens invités restent accessibles par leurs crédits. Genres, Pays, Compositeurs et Labels offrent d’autres points d’entrée vers les mêmes disques.

## Choisir une présentation

Utilisez les icônes du header pour passer entre grille, liste et Cover Flow quand ces présentations sont proposées. Dans Albums, Cover Flow est la présentation initiale. Cliquez sur une pochette latérale pour la ramener devant, utilisez les flèches du clavier ou glissez la rangée. Les lettres sous la réglette sont cliquables.

La réglette de taille agrandit les pochettes dans les vues compatibles ; elle est inactive en Cover Flow. Un double-clic sur son icône rétablit la valeur par défaut. La préférence générale se trouve dans les réglages d’apparence.

## Affiner sans perdre le fil

Les icônes année et alphabet affichent ou masquent chacune leur réglette. Une réglette masquée ne filtre pas. Déplacez une borne pour limiter la sélection, ou glissez la plage entière. Les barres représentent la répartition du catalogue, et le compteur indique les résultats.

Tout afficher efface les restrictions de la sélection. L’icône Nouveautés dans Albums conserve les ajouts des trente derniers jours. Une date d’ajout inconnue ne prouve pas qu’un album est récent.

Dans Pays, tournez ou zoomez le globe. Commande sur Mac, ou Contrôle sur Windows/Linux, permet de choisir plusieurs pays. La même sélection multiple est disponible pour les tags.

## Chercher autrement

La recherche générale couvre le catalogue ; les vues Votre musique disposent d’un contexte de recherche adapté. La loupe ouvre la recherche avancée : titres, artistes, années, formats, fréquence, profondeur de bits, notes, tags et favoris peuvent se combiner. Le résultat peut devenir une [collection](your-music.md). Les champs non renseignés restent inconnus, pas égaux à zéro.

Un clic sur l’année d’un album retire les autres critères : ajouts récents, compositeurs, pays, genres et recherche. Chaque nouveau label initialise sa propre période. Les barres des réglettes comptent les albums de la vue courante, y compris les compilations et les albums sans artiste identifié.
