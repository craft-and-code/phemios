# Shared SVG identity proposals

These proposals preserve the established off-white text, dark surface and button-accent dot. Phémios retains the approved p-dot silhouette; Aède uses a matching geometric a-dot. The application icons contain paths only and keep transparent rounded corners. The wordmarks have transparent backgrounds, intended for dark surfaces; their text remains editable in the site's Helvetica/Arial font family. These proposals do not replace the active app resources or website favicon without selection.

- `phemios-wordmark.svg`, `phemios-icon.svg`
- `aede-wordmark.svg`, `aede-icon.svg`
- `comparison.svg`: self-contained review board embedding the four proposals.
